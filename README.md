## Overview

These are test programs to validate the new PCB. The are three.

You must open each subfolder separately in the pioarduino IDE.

  1. i2c-demo: This will test the external connector using the test board provided. It has an I2C device and four LED's.

  2. mag-swich-dem: This will test the magnetic switch and the indicator LED.
  3. NTC-POC reads the NTC temperature sensor. It should be tested with a fixed 10K resistor before using the actual sensor.
